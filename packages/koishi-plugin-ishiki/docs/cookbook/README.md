# ishiki cookbook

v1 已确认的设计。实现以这里为准，不表示当前源码已经实现全部契约；具体接口与存储布局在实现计划中落实。

| [02-attention.md](./02-attention.md) | 主心智、focus / awareness、工具选址 |
| [03-context.md](./03-context.md)     | 三区、帧重建、连续性                |
| [04-rendering.md](./04-rendering.md) | 消息事实、扩展注册、原生消息投影    |

**v1 身份：** Koishi 插件。一个 profile = 一个主心智 = 一个 Agent。上下文按三区拼。

**v1 不做：** 线性 append-only、可插拔上下文引擎、athena 式 awareness 附加上下文、渲染结果缓存、中间 `ishiki.render.*` 类型、通用 state delta 服务、把 profile 暴露到配置页、把 LLM 摘要当作连续性的必要路径。focus-change delta 保留。

**核心契约：** 扩展控制可见性，core 分类并包装；触发由 profile 级引擎独立评估。先评估，再由 `agent.send` 统一提交。focus 首次从配置初始化，重启恢复已有状态。上下文采用三区与机械剪枝；检查点先保存、后切换；扩展投影失败按事件隔离。

## 本轮已收口

| 主题       | 决定                                                                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 触发       | 同一 profile 串行评估新增事实、已有历史与运行时状态，再 send；不等待 turn；v1 仅 @ 自己、私聊、content 字面关键词；评估失败仍以 `trigger: false` 提交 |
| 显式运行   | 插件可直接 `agent.send` 请求运行，跳过 ishiki 策略；不另开循环，不强制可见                                                                            |
| focus      | 首次用 profile 配置，重启恢复已有状态；`change_focus` 默认不带历史，仅显式指定条数时附在工具结果中                                                    |
| 历史保留   | 无切换时按原始 AgentMessage 取尾部 N 条，工具配对向前补齐可超过 N；有切换时整代剪枝；两段历史允许重复，不跨区去重                                     |
| 剪枝       | 移除 reasoning 与多模态附件；所有工具结果统一按配置保留首尾、标记中间省略，不区分成败，不扩展工具错误元数据                                           |
| 容量与保存 | 超模型窗口时报错，不额外裁减或自动重试；检查点保存成功才切换工作区，保存失败不切换                                                                    |
| 扩展失败   | 渲染器缺失或可见性 / 渲染抛错时记录并跳过该事件；重复注册拒绝后者，保留已有注册                                                                       |
| 范围       | 只覆盖真实来源，不为假设性 guild-only 事件加分发规则；不增加触发定时检查、复杂意愿或策略仲裁                                                          |

## 实现计划中落实

- 公共来源字段、事件注册和 profile 级触发引擎的具体接口；避免扩大 `EventSource` 导致无关消费者连锁修改。
- 初始 focus、历史窗口、关键词及截断预算等配置字段、默认值与校验；现有行为不再列为未决项。
- checkpoint / 帧快照的持久化布局、恢复步骤、流投影接法和派生消息 ID。
- 注册生命周期、错误隔离，以及原生消息转换的字段保真。

本轮只更新设计记录，不授权源码实现。实现计划需列出受影响文件与调用方、旧路径切换及验收场景，确认后再执行；线性模式、可插拔引擎和复杂意愿算法不阻塞 v1。
