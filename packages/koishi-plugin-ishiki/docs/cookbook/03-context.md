# 03 · 上下文

模型看到的是这个场景自己的近期记录，不是一份写回磁盘的帧。

稳定的部分在前面：人格、场景补充、系统模板、工具说明。后面是事实流的尾部，最多 `maxMessages` 条（默认 40），加上这些事实之后的工具轨迹。更早的事实仍在 `session.jsonl` 里，只是不送进这一次请求。

投影不写回事实流。旧日志里的 `ishiki.checkpoint` 会被跳过，不再当成模型要读的正文。

## 卸载

场景空闲超过 `evictMs`（默认 2 分钟）后，agent 停止，运行时离开内存。事实流留在磁盘上。下一次唤醒重新挂载，读的还是同一份文件。

## 连续性

- 工具调用与结果保持配对。裁掉尾部以外的事实时，连同它们前面的工具轨迹一起裁掉。
- 每条事实只在一个场景的流里出现一次。
- 卸载不产生第二份真相。
