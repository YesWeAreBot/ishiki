## 引擎配置段

三族引擎的 `engine` 字段取值与对应配置段：

### context

| engine | 配置段 | 字段 |
| --- | --- | --- |
| `standard` | `standard` | `maxTokens: number`（默认 32000）、`refillRatio?: number`（0–1，默认 0.8） |
| `v3` | `v3` | `maxMessages: number`（默认 50）、`keepFullTurnCount: number`（默认 2）、`memoryBlocks: boolean` |

### wakeup

| engine | 配置段 | 字段 |
| --- | --- | --- |
| `standard` | `standard` | `direct/atSelf/quoteSelf: boolean`（均默认 true）、`keywords: string[]`（默认空） |
| `v3` | `v3` | `base: 12`、`atMention: 100`、`isQuote: 15`、`isDirectMessage: 40`、`keywords: []`、`keywordMultiplier: 1.2`、`defaultMultiplier: 1`、`maxWillingness: 100`、`decayHalfLifeSeconds: 600`、`probabilityThreshold: 55`、`probabilityAmplifier: 0.04`、`replyCost: 35` |
| `jev` | `jev` | `apiKey`（或环境变量 `TYPESAFE_API_KEY`，**必需**）、`model: "jev-latest"`、`endpoint: "https://api.typesafe.ai/v1/systemone"`、`threshold: 0.5`、`cooldownMs: 30000`、`timeoutMs: 1500`、`historyMessages: 8`、`instruction: ""`、`interests: []`、`rules: Partial<standard>`（默认 `{ direct: true, atSelf: true, quoteSelf: false, keywords: [] }`） |

### toolcall

| engine | 说明 |
| --- | --- |
| `native` | 模型原生 function call，无配置段 |
| `v3` | JSON OUTPUT 协议，每步输出 `thoughts`（observe/analyze_infer/plan 三段）+ `actions` |
| `hermes` / `qwen3coder` / `morph-xml` / `yaml-xml` | 对应文本输出协议，由解析引擎从纯文本中提取调用，无需模型原生支持 |

协议引擎均无 profile 级配置段。

## 默认 profile 示例

仓库 `packages/koishi-plugin-ishiki/resources/profile.example.yml` 是带逐段注释的官方示例，包含 channel/cross/v3/jev 四份完整配置，与本文档字段一一对应，是最权威的样例。

## 旧字段迁移

早期版本（如 boilerplate 中的 `Cat` 示例）使用过 `scenes`、`innerThoughts`、`description`、`context.standard.maxChars` 等字段，当前 Schema 不再支持：场景拆分由 `channels` 认领承担，字符预算改为 `maxTokens`，`innerThoughts` 已移除（内心独白始终私有）。加载含未知字段的 profile 不报错（字段被忽略），但行为以当前默认值为准；建议迁移。
